## 晚 · 信号位置优化（用户要求：提前一根 + 过滤前根是卖的买点）

**改了什么**（indicator.py 新增 `postprocess_signals()`，两个参数在主流程与回测都透传）：

| 参数 | 值 | 作用 |
|---|---|---|
| `signal_shift` | -1 | buy/sell 索引整体前移一根，越界丢弃 |
| `skip_buy_after_sell` | true | 先平移再判断：买点若前一根是卖点 → 丢弃 |
| `ma7_lead_pct` | 0.3 → **0** | 提前量归零；它与平移做同一件事，叠加互相干扰 |
| `turnover_rel_min` | 0.95 → **1.0** | 重扫后的最优 |

**效果（±1 根、同向匹配）**：精度 56.1 → 56.5%，召回 57.4% 不变，信号 66 → 62。
**关键指标**：信号相对真值的中位偏移 −1 → **0**，同根命中率 5% → **45%**（以 lead=0.3 旧口径算是 6% → 46%）。
分序列：光线 60m 73→82%、光线日线 59→62%、成飞日线 65→67%、宁德 60m 43→38%、成飞 60m 30→27%。

**重要结论：靠加大 `ma7_lead_pct` 无法实现「整体提前一根」。** lead 0→2.0，中位偏移只从 −1 走到 +1（同根率始终 7~8%），精度却从 53% 掉到 35%——提前量只让信号在 MA7 附近抖动，不能让整条序列平移，且提前触发的点大量落在震荡区变假信号。

**必须记住的口径警告**：`signal_shift=-1` 是「标注对齐」，不是「更早算出」。等于在回测/实盘中提前一根使用未来信息（t 根的信号标到 t−1 根，而 t−1 收盘时不知道）。**实盘推送必须设回 0**，已在 config 注释与报告红框里写明。

**图上的改进**：`tools/plot_truth_vs_algo.py` 现在把「真值区间之外」的算法信号画成 30% 透明（否则左侧历史信号会被误读成假信号）。
